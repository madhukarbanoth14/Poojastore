# Feature: English + Telugu (i18n)

The customer app is bilingual. UI chrome is translated in Flutter ARB files. Catalog/content follows `Accept-Language` / `?language=`.

## Locales

| Code | Language |
|------|----------|
| `en` | English (default) |
| `te` | Telugu (తెలుగు) |

Switch from login (segmented control) or any home AppBar translate icon. Choice is stored on device and, when logged in, on `User.preferredLanguage` via `PATCH /auth/me`.

## Flutter

- ARB: `apps/mobile/lib/l10n/app_en.arb`, `app_te.arb`
- Telugu UI uses Noto Sans Telugu
- API client sends `Accept-Language: en|te`
- Vidhi and kids lists pass `language=` so Telugu rows are returned

## API

- `PATCH /api/v1/auth/me` `{ "preferredLanguage": "te" }`
- `GET /vidhi?language=te`, `GET /kids/stories?language=te`
- Product names/descriptions localize from `metadata.i18n.te` when `Accept-Language` starts with `te`
- Pooja samagri catalog (`catalog=pooja-samagri`) includes Telugu item names from `docs/pooja_samagri.xlsx`

## Seed

`npx prisma db seed` writes Telugu vidhis (`*-te` slugs), kids stories, kit translations, and pooja samagri. Re-seed after pull.
